# Profile repository maintenance

- Use feature branches and draft pull requests for changes; never merge without user approval.
- Keep claims grounded in published repositories and verifiable results.
- Distinguish proposed research from completed or peer-reviewed work.
- Never disclose employer, customer, supplier, or other confidential information.
- Validate Markdown links and formatting before requesting review.
- Do not add unverified metrics, credentials, academic affiliations, or certifications.
